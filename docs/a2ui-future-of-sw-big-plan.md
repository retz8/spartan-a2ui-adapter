# A2UI Demo — Phases

> Start small, build up to composition.

---

## Alongside: A2UI OSS Contribution

## Phase 0 — `a2ui-github`
Single brand, to understand the A2UI pipeline. No composition. (Primer + GitHub MCP)
Deliverable: catalog + agent + adapter + playground (thin renderer for standalone verification)

## Phase 1 — `a2ui-jira`
Repeat the same pattern with a different design system. (Atlassian DS + Jira MCP)
Deliverable: catalog + agent + adapter + playground (same structure as github)

## Phase 2 — `a2ui-super-host` (working title)
Compose multiple agents. A real host with orchestrator + compositor.
Deliverable: orchestration host (registers both brand adapters + connects both agents)

## Phase 3+ — Expansion (later)
- Add a third brand agent
- Two-layer catalog (structure / style) experiment
- Registry pattern — public registration → summoned by any host
- Hyperpersonalization / richer composition
